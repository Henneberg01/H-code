## Symbols are the real compiler operations

Symbol `∑` performs numeric reduction, `⇢` maps a typed unary function to a new typed sequence, and `⌕` filters a sequence using a typed Boolean predicate. These are real AST/typechecker/runtime constructs; not a replace-text convenience, one-off app macro or pre-computed output. The full H-Code source is stored separately from its TypeScript equivalent at `compact/canonical20/programs/10-generic-collection-transforms.{hc,ts}`.

```hcode
≔nums←⟦-3,0,7,11⟧;
print(∑nums);
print(⤒(nums⇢(*2)));
print(⤒(nums⌕(>0)));
```

The same **entire** source also covers mapping/filtering strings, filtering Booleans, mapping/filtering structurally typed records through ordinary typed functions, mapping nested sequences to lengths, and reducing/mapping explicitly typed empty sequences. The corresponding idiomatic TypeScript uses native `.reduce()`, `.map()` and `.filter()`, typed arrays and a record type. A proper compiler must infer/validate each compatible element and output type.
